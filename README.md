Quantum Laboratory поєднує наукове Python-ядро, двоспінові Bell-експерименти, 2–6 спіновий TFIM, Stage 5B Dynamic Receiver і 3D-пісочницю Orbital Lab. Фізичні величини обчислюються у Python API; 3D-сцена є інтерактивною схемою системи, а не масштабованою геометричною моделлю.

## Windows Desktop

Проєкт містить Electron-оболонку, React/Three.js інтерфейс та інструменти пакування Python-ядра. Інсталятор і portable EXE не є частиною цього вихідного релізу; публічні бінарні збірки з'являться після окремої перевірки. Інструкції й обмеження: [Quantum Laboratory Desktop](docs/desktop/README.md).

## Запуск із вихідного коду у Windows

1. Встановіть Python 3.10 або новіший із Python Launcher (`py`).
2. Запустіть `start_windows.bat`. Скрипт створить `.venv`, встановить залежності локально, збудує браузерний застосунок, вибере доступний loopback-порт, перевірить готовність API та UI й відкриє браузер за перевіреною адресою. Старі процеси на інших портах не завершуються.
3. Для автоматичних регресійних перевірок запустіть `run_tests_windows.bat`. Тести аналізу Hensen потребують окремо отриманих оригінальних файлів; джерела й контрольні суми описані в [реєстрі джерел](docs/source-register.md).

Перший запуск потребує доступу до індексу пакетів Python. Середовище ізольоване в `.venv`; глобальні пакети не змінюються.

## Що доступно

- Підготовка чотирьох Bell-станів, локальні обертання й проєктивні вимірювання.
- Локальні та спільні ймовірності, повна матриця густини після локальних каналів, кореляції, concurrence і CHSH.
- Параметризоване фазове затухання як Kraus-канал для одного спіну або локально для `ρ_AB`; параметр не калібрований для установки Hensen.
- Окремі повзунки `λ_A` і `λ_B`; 2D sweep будує карти concurrence, фіксованого й оптимізованого CHSH, спільних кореляцій і локальних Born-ймовірностей.
- Для незміненого singlet sweep незалежно перевіряє `q=(1−λ_A)(1−λ_B)`, `C=q` і `S_max=2√(1+q²)`; фіксовані осі CHSH показуються окремо. Якщо перед каналами ввімкнені локальні обертання, ядро перераховує стан, а UI не застосовує еталон без обертань.
- Вибірковий тест CHSH для чотирьох пар осей.
- Контроль no-signaling з незалежним локальним відліком B та обчисленням точності декодування.
- Графік когерентної еволюції, сфери Блоха, порівняння повторних запусків.
- Відтворювані записи JSON/CSV з усією сіткою параметрів, чисельними даними всіх графіків, Plotly-описами та експортованими PNG/SVG-файлами.
- Відновлення конфігурації з JSON.
- Вкладка «Наукова валідація»: незалежне відтворення аналізу сирих даних Hensen et al. (2015), контроль SHA-256 і окремий статус відповідності реальному приладу.

## Python API

```python
from quantum_lab.experiments import run_state_experiment, run_chsh_experiment, run_phase_damping_sweep

state = run_state_experiment("singlet", shots=10_000, seed=42, dephasing_a=0.2, dephasing_b=0.4)
bell_test = run_chsh_experiment(shots_per_setting=10_000, seed=42, dephasing_a=0.2, dephasing_b=0.4)
sweep = run_phase_damping_sweep("singlet", seed=42)
```

`quantum_lab` містить фізичні рівняння та статистику; `app.py` відповідає тільки за елементи керування, відображення й виклик API.

## Наукова довідка та формули

У Orbital Lab є локальний розділ **«Довідка»** з пошуком і 21 тематичною сторінкою. Він постачається разом із frontend і доступний без мережі; джерела відкриваються за DOI лише за запитом. Формули відображаються локально KaTeX, а контекстні кнопки біля `J`, `h`, `λ`, CHSH, concurrence і trace distance ведуть до пояснення змісту та одиниць.

Реєстр джерел — [`docs/source-register.md`](docs/source-register.md), BibTeX — [`docs/references.bib`](docs/references.bib), формули й припущення реалізованого ядра — [`docs/scientific_model.md`](docs/scientific_model.md). У рівняннях вживається порядок базису `|q₀…qₙ₋₁⟩` із `q₀` як лівим фактором; TFIM використовує σ-нормування та відкриті межі. Ці локальні домовленості не є твердженнями про калібрований експериментальний прилад.

Для `H/ℏ = −J Σ σᶻᵢσᶻᵢ₊₁ − h Σ σˣᵢ` величини `J` і `h` задаються в `s⁻¹` (кутова частота), час — у секундах. Фізична енергія дорівнює `H=ℏ(H/ℏ)`. Використані формули зіставляються з Python scientific core; GUI не реалізує окремі фізичні розрахунки.

### Stage 5A: відтворюваний триспіновий TFIM-приклад

Перший етап Stage 5 додає N-спінове ядро та замкнену динаміку відкритого одновимірного transverse-field Ising model (TFIM). Наступний навчальний приклад використовує саме наявне наукове ядро і записує вихідні ряди спостережуваних величин разом із конфігурацією:

```python
import numpy as np

from quantum_lab.experiments import run_tfim_experiment
from quantum_lab.storage import save_experiment
from quantum_lab.tfim import FieldSchedule

times_s = np.linspace(0.0, 8.0, 101)
initial_ket = np.zeros(8, dtype=complex)
initial_ket[0] = 1.0  # |000> у big-endian базисі

run = run_tfim_experiment(
    n_spins=3,
    J=1.0,  # s^-1; навчальне значення, не калібрування установки
    h_schedule=FieldSchedule.constant(0.7),  # s^-1
    initial_state=initial_ket,
    times_s=times_s,  # секунди
    seed=123,
)
assert run["results"]["status"] == "success"
mean_z = run["results"]["observables"]["mean_sigma_z"]
nearest_neighbor_zz = run["results"]["observables"]["nearest_neighbor_zz"]

paths = save_experiment(
    run["results"], run["configuration"], "experiments/stage5_three_spin"
)
print(paths["json"], paths["csv"])
```

Результат містить 101 точку для `⟨σᶻ⟩`-поляризації та для кожного OBC-зв'язку `(0,1)` і `(1,2)` значення `⟨σᶻᵢσᶻᵢ₊₁⟩`; повні ряди, часи, початковий стан, параметри й діагностика методу потрапляють до запису. Для цієї фіксованої сітки очікується `ptp(mean_z)≈1.9703230076`, а розмах обох сусідніх кореляцій — `≈0.5844617965`. Це демонстрація когерентної скінченної системи, а не експериментальний прогноз. Stage 5A надає багатоспінове ядро та TFIM-еволюцію через Python API. Dynamic Quantum Receiver, Deviation Analyzer і Quantum Domino додані у Stage 5B; інтерфейс Stage 5C викликає те саме наукове ядро через локальний Python API. Оригінальний аналіз Hensen не змінюється. Формули, чисельні обмеження і посилання наведені у [реєстрі наукової моделі](docs/scientific_model.md); незалежні QuSpin/QuTiP перевірки описані у [звіті Stage 5A](docs/stage5_validation.md).

## Наукове використання

Поточна модель не включає реальні квантові точки, просторово-часові умови, втрати, калібровані T1/T2-декогеренцію, шуми керування або повні моделі детекторів. Фазове затухання доступне лише як параметризований канал без Hensen-калібрування. CHSH-демонстрація не закриває експериментальні loopholes. Перед використанням у науковій роботі прочитайте [реєстр моделі](docs/scientific_model.md), [посібник для дослідницької роботи](docs/research_guide.md) і перевірте джерела.

## Наукова валідація

Запустіть вкладку «Наукова валідація» для повторення аналізу Hensen 2015 із незміненого набору Figshare/4TU. Результат `VALIDATED` стосується відтворення фільтрів і опублікованих статистик із сирих даних; порівняння ідеального симулятора з апаратною установкою позначено `NOT IMPLEMENTED`. Оригінальні файли та маніфести версій/хешів містяться у `data/references/`. Методика, допуски, вихідні значення та відмінності від Hensen 2016 описані у [документації наукової валідації](docs/scientific_validation.md).

## Stage 5B — приймач і Quantum Domino

Stage 5B додає повний стан A⊗R, ізольовану TFIM-еволюцію приймача, тест локальних CPTP-дій передавача, Gaussian positive control і аналіз exact predictions окремо від незалежних вимірювань. Протокол, дані та фактичні результати наведені у [Stage 5B validation report](docs/stage5_validation.md#stage-5b-повторення-ізольованого-приймача). Оригінальні дані й аналіз Hensen залишаються незмінними.

## Stage 5C — інтерактивна лабораторія Orbital Lab

Запустіть `start_windows.bat`: він запускає локальний Python API, збирає React/TypeScript інтерфейс і відкриває Orbital Lab у браузері. Керування станами, TFIM, вимірюваннями, каналом фазового затухання, аналізом, Quantum Domino та переглядом даних Hensen викликає Python API; JavaScript не містить окремої фізичної моделі. Схематичні вузли та вектори Блоха є візуалізацією розрахованих величин, а точні очікування відокремлено від випадкових вибірок. Розраховані траєкторії не є безперервним спостереженням однієї системи. Записи конфігурації й результатів можна зберігати та експортувати у JSON/CSV. Hensen 2015/2016 показані як окремі відтворення оригінальних наборів даних; повна модель апаратури й калібровані параметри залишаються поза реалізацією.
