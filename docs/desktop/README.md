**Автор:** Anton Volos (Волос Антон Володимирович). Авторський програмний код поширюється за MIT License; сторонні бібліотеки й дані мають власні умови. Цей вихідний реліз не містить інсталятора чи portable EXE. Локальні збірки не є офіційними релізними файлами.

## Стан desktop-збірки

Застосунок використовує Electron-вікно, React/Three.js інтерфейс і локальний Python backend. Під час запуску backend слухає лише `127.0.0.1` на доступному порту; Electron очікує готовності `/api/health`. Результати користувача зберігаються у профілі Windows, поза каталогом програми. Вікно запам'ятовує розмір і положення.

Поточний локальний кандидат перевіряли на Windows 11 x64. Windows 10 x64 окремо не перевірено. Пакет не має цифрового підпису. Публічних EXE поки немає; перед окремим бінарним релізом потрібно повторно зібрати їх із оприлюдненого коміту, перевірити залежності та створити контрольні суми.

## Можливості та межі

Orbital Lab містить 3D-камеру, вибір спінів, згортання панелей та графіки. Підготовка станів, локальні операції, вимірювання, CHSH, concurrence, фазове затухання, TFIM, Dynamic Receiver, Deviation Analyzer, збереження й експорт використовують Python scientific core. Сирі Hensen 2015/2016 дані не входять до цього вихідного знімка; аналіз можна перевірити після окремого отримання первинних наборів за джерелами в `docs/source-register.md`. 3D-координати спінів є схематичними, не просторовою траєкторією.

## Запуск із вихідного коду у Windows

Потрібні Python 3.10+ та Node.js для локального frontend. Із кореня репозиторію запустіть:

```bat
start_windows.bat
```

Скрипт створює локальне Python-середовище, встановлює залежності, збирає frontend, знаходить вільний loopback-порт і чекає готовності API перед відкриттям інтерфейсу у браузері.

## Збірка desktop-пакета розробником

На Windows із Python 3.13 та Node 22:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_desktop.ps1
```

Скрипт збирає React frontend, пакує Python backend через PyInstaller та формує NSIS setup і portable за допомогою electron-builder. Результати залишаються в `desktop/build` і `desktop/release`; їх не слід додавати до Git. Перевірте backend smoke-тестом:

```powershell
.\.venv\Scripts\python.exe .\scripts\smoke_desktop_backend.py .\desktop\build\QuantumLaboratoryCore\QuantumLaboratoryCore.exe
```

## Безпека

Renderer працює з `contextIsolation` та sandbox, без `nodeIntegration`. Electron обмежує запити власним loopback origin; випадковий токен сесії потрібен для API й статичних файлів, а backend перевіряє Host і Origin. Зовнішні мережеві інтерфейси не відкриваються. При закритті вікна завершується лише дочірній backend, запущений цим застосунком.
