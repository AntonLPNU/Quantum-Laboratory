# Quantum Laboratory — перевірка публічного вихідного знімка

Дата перевірки: 28.10.2026. Перевірявся чистий знімок вихідного коду для Research Preview 0.5.0. Він не містить інсталятора, portable EXE, сирих даних Hensen або повного запису Stage 5B.

## Результати

| Перевірка | Результат |
|---|---|
| Python у чистій публічній копії | 190 тестів: 184 пройшли, 6 пропущено через відсутність зовнішніх даних Hensen; помилок немає |
| Python у локальній робочій копії з первинними наборами | 190 тестів пройшли до пакування; дані не копіювалися до публічного знімка |
| Frontend | 32 тести у 7 файлах пройшли |
| Production build | Успішний; Vite повідомляє про великий JS chunk (~1.52 MB до gzip), це попередження, не помилка збірки |
| Маніфест відтворюваності | `research/check_manifest.py --included-only`: PASS, 1 включений артефакт перевірений |
| Перевірка diff | `git diff --check`: PASS перед фіксацією |
| Пошук поширених секретів і приватних шляхів у знімку | 0 збігів за використаними шаблонами; `gitleaks` у середовищі не встановлено |

Шість пропущених тестів потребують Hensen 2015/2016 raw-файлів. Після окремого завантаження первинних наборів і звірки SHA-256 їх можна запустити повністю. API й Streamlit тепер явно повідомляють, що цих файлів немає; результати Hensen не підміняються демонстраційними даними.

## Межі перевірки

- Наукові алгоритми й дані не змінювалися; зміни для публічного знімка стосуються ліцензійної документації та обробки відсутніх зовнішніх файлів/локального звіту.
- Незалежні QuTiP/QuSpin чисельні звірки зафіксовано в наукових документах Stage 5; їх не повторювали в межах цього пакування.
- Браузерну сесію та Windows EXE у чистому знімку повторно не перевіряли. Бінарні файли не входять до цього вихідного коміту.
- Windows 10 x64 не перевірено окремо. Windows 11 x64 перевіряли під час попередньої локальної desktop-перевірки; її локальні EXE не є частиною цього коміту.
- Публічний реліз не має цифрового підпису, оскільки бінарний реліз не створювався.
