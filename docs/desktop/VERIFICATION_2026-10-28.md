## Фактично виконані перевірки

- Python: 190 тестів, успішно.
- Frontend: 32 тести в 7 файлах, успішно; production build успішний.
- Автономний smoke-тест останньої упакованої Python-збірки: PASS. Перевірено 14 шляхів: авторизація, офлайн-інтерфейс, підготовка стану, phase damping, CHSH, TFIM, Dynamic Receiver, Deviation Analyzer, Hensen 2015/2016, заблокований підтверджувальний запис Stage 5B, збереження, повторне завантаження та CSV-експорт.
- Незалежна звірка Stage 5B: QuTiP 5.3.0 і QuSpin 1.0.1 повернули PASS із межею 1e-8. Для гладкого поля найбільше відхилення стану QuTiP за нормою L2 становило 9.94e-10; для статичного випадку 5.13e-11. Для QuSpin: 2.84e-13 (стале поле) і 3.56e-13 (відрізково-стале поле).
- Frontend і desktop npm audit: 0 відомих вразливостей на дату перевірки.
- Інсталятор встановлено в окремий тестовий каталог; завершення інсталяції — код 0. Встановлену програму запущено без браузера, Python або Node з боку користувача. Python API підключився на випадковому loopback-порту.
- Portable EXE запущено з тимчасового каталогу. Вікно показало підключений Python scientific core і наукові результати. Після закриття тестових вікон обидва зафіксовані backend-порти перестали прослуховувати localhost.
- Перевірено відкриті одночасно інструменти, Inspector і графік. У компактному вікні 1272×706 вони не перекриваються; сцена доступна. Кнопки згортання/розгортання на всіх трьох блоках. Відображення 3D-вузлів позначене як схема, не просторовий рух.
- Офлайн-довідка перевірена в установленій збірці до останнього виправлення панелей; джерела довідки в останній збірці не змінювалися.

## Відомі межі

- Перевірка виконана на Windows 11 x64. Окремого випробування Windows 10 x64 на іншій машині не було.
- Пакет не має цифрового підпису; Windows може показати попередження.
- Показник 60 FPS у вікні був миттєвим, не тривалим профілюванням.
- Великий JS bundle лишився без поділу на чанки; це попередження збірки, не помилка запуску.
- Власник ще має визначити ліцензію авторського коду, авторські метадані й надати окремий дозвіл на публікацію.
- Git-дерево вже містило змішані незакомічені зміни Stage 5B/5C/5D. Історію та індекс не змінювали, масового додавання не виконували. В обмеженому середовищі Git повідомляє про відсутність work tree; запуск у звичайному Windows-процесі правильно бачить робоче дерево.
